圖形 ⇄ 聲音

在左邊畫一個封閉圖形。它會被拆成一組旋轉圓（傅立葉級數），每個圓變成一個音調；播放出來的和弦，就是這個圖形的頻譜。

z(t) = Σ ck · eikt　　音調 fk = 1000 + 50k Hz，振幅 = |ck|，相位 = arg ck

手繪 — 用滑鼠或手指畫圖

還原 — 由聲音解出的圖形

先在左邊畫一個圖形。

運作方式

畫好的路徑被當成複數 x + iy，等弧長取樣 256 點後做離散傅立葉轉換，得到係數 ck（k = −15…15）。k = 0 是中心點，改用一個固定振幅、相位 0 的「領航音」（1000 Hz）代替，接收端以它為基準校正音量與相位。解碼時對麥克風訊號在 31 個頻率上做相關運算，取得 ck 後，用旋轉圓重新畫出圖形。時間延遲只會讓圖形的起點移動，不會改變形狀。使用麥克風時請調高喇叭音量，並在安靜環境下進行。
